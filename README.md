# Práctica de HTML y CSS

Sitio estático de dos páginas, hecho para practicar maquetación con HTML y CSS.

## Contenido

- `index.html`: página principal con menú de navegación y submenú desplegable, galería de tarjetas (temática de cerezos en flor) y un formulario de inicio de sesión de maqueta, sin backend.
- `productos.html`: tabla de productos con estilos propios.
- `style.css`: estilos generales de las dos páginas.
- `tabla.css`: estilos de la tabla.
- `assets/`: imágenes del sitio.

## Ver el sitio

Abre `index.html` en el navegador. No requiere instalación.

## Temas practicados

Menús de navegación con submenú, tarjetas, formularios y tablas con estilos.
